# UI and functional audit — 2026-10-21

Inspected both React routers, all workflow pages, admin catalogue editor, authentication providers, backend routes, migrations, styles, and existing tests before implementation. `.neon` selects `codex-customer-dev`; the earlier Neon integration report identifies this as the isolated development branch. Production is outside the scope of migrations and QA.

Shared concerns: generic loading/error UI, untranslated customer labels, very large mobile headings, no safe draft ownership boundary, missing completion/review lifecycle. Private API caching is already disabled. Existing API and browser tests cover baseline auth/catalogue. Upload storage, technician assignment, actual slot capacity and service-area configuration are not established end-to-end; do not invent these records or availability.
