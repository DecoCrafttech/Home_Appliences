# Fixbeez PWA Design System for Codex

This kit intentionally contains the **original PNG logo only**, not the incorrect hand-redrawn SVG from an earlier kit.

## Files
- `CODEX_FULL_PROMPT.md`: complete implementation brief for all three PWAs
- `design-system/tokens.json`: exact shared color/shape/spacing values
- `design-system/theme.css`: ready-to-adapt shared CSS and components
- `design-system/honeycomb-pattern.svg`: small decorative honeycomb background asset (this is **not a logo**)
- `assets/fixbeez-original-logo-transparent.png`: original transparent PNG logo
- `assets/fixbeez-original-logo-white-bg.png`: original logo on white background
- `references/customer-ui-approved.png`: latest customer direction
- `references/customer-full-flow.png`: earlier screen-by-screen direction
- `references/all-three-pwas.png`: earlier overall role reference

## Codex steps
1. Extract the kit into `<repo-root>/design-kit/fixbeez/` (keep original app folders intact).
2. In Codex, use this exact instruction:
   `Read design-kit/fixbeez/CODEX_FULL_PROMPT.md and implement every requirement against my existing apps/customer-pwa, apps/admin-pwa and apps/technician-pwa. Use the exact PNG logo; ignore the old SVG logos. Preserve existing APIs and workflows.`
3. Ask Codex to run available lint/typecheck/build tests, then review its implementation report.

Palette: yellow `#FFC928`, orange `#FF9500`, purple `#512DA8`, white cards `#FFFFFF`, warm canvas `#FFFCF7`, navy text `#1F2638`.
